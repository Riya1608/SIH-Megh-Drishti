# 🌦️ SIH – Megh Drishti

> **Smart India Hackathon Project | Team Megh Drishti**

A weather-focused project developed as part of **Smart India Hackathon (SIH)**, exploring weather nowcasting and an early-warning system.

---

## 🚀 Project Overview

**Megh Drishti** focuses on weather-related prediction and early-warning capabilities.

During the project, I worked with the project's Python/ML environment through **Google Colab**, setting up the required dependencies, testing the model architecture, running the early-warning system, and checking its supporting map configuration.

---

## 🧠 My Contribution

My work included:

- 🔹 **Google Colab Setup** — Set up and prepared the project environment for experimentation.
- 🔹 **ML Environment Testing** — Installed and tested Python libraries required by the project, including PyTorch, NumPy, Pandas and SciPy.
- 🔹 **Model Loading** — Loaded and tested the `MultiTaskWeatherNowcastingNet` architecture.
- 🔹 **Early-Warning System** — Started and tested the project's early-warning system server.
- 🔹 **API Testing** — Checked the local server/API connection using HTTP requests.
- 🔹 **Map Configuration** — Inspected the project for CARTO, basemap and tile-layer configuration.
